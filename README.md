# How to Explain React State and Props to People Like Frank

A small React demo to illustrate **state** and **props**: a list of users (state) passed down to `User` components (props), with a button that updates state.

## Stack

- **React 18**
- **Vite** (build and dev server)
- **Vitest** + **Testing Library** (tests)

## Commands

| Command        | Description                |
|---------------|----------------------------|
| `npm run dev` | Start dev server (Vite)    |
| `npm run build` | Production build → `dist/` |
| `npm run preview` | Serve production build     |
| `npm test`    | Run tests (Vitest)         |

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
